# Round 1 종합 결과 — 해외 사용자 데이터 저장 방식 변경

## 참여 관점

- 법무 (Legal)
- 인프라 (Infrastructure)
- 기획 (Product)
- 개발 (Engineering)

## 배경

현재 서비스는 전 세계 사용자 데이터를 단일 리전 쌍(주 리전 + 백업 리전)에 함께
저장한다. EU 거주 사용자 비중이 늘면서 데이터 저장 위치를 둘러싼 두 팀의 입장이
Round 1에서 정리됐다.

## 충돌 #1: EU 사용자 데이터 저장 리전

- **법무**: GDPR 제44조에 따라 EU 거주자의 개인정보는 반드시 EU 역내에서만
  처리·저장돼야 한다. 이미 지난달 개인정보보호위원회에 "EU 사용자 데이터는
  EU 리전에만 저장한다"고 공식 확약서를 제출한 상태다. 역외로 단 한 건이라도
  복제되면 확약 위반이며, 담당 임원에 대한 형사 처벌 대상이 될 수 있다.
  암호화 여부와 무관하게 역외 저장 자체가 확약 위반이라는 점을 위원회와 이미
  합의했다. **양보 불가.**
- **인프라**: 3개 글로벌 엔터프라이즈 고객사와 체결한 SLA 조항 7.2 원문은
  다음과 같다 — "모든 사용자 데이터는 서로 다른 대륙에 위치한 최소 2개
  리전에 동시 복제되어야 한다(예: 유럽-북미, 아시아-유럽 조합). 동일 대륙
  내 복제는 본 조항을 충족하지 않는다." 지난 분기 계약 갱신 시 인프라팀이
  직접 검토·서명한 확정 조항으로, 추가 해석의 여지가 없다. EU 리전을 여러
  곳 두더라도 전부 유럽 대륙이므로 이 조항은 충족되지 않는다. 계약 위반 시
  지난 분기 매출의 15%에 해당하는 위약금이 발생하며, 세 고객사 모두 계약서에
  예외 조항을 두지 않았다. **양보 불가.**

## 충돌 #2: 마이그레이션 일정

- **기획**: 다음 분기 실적 발표 전에 데이터 저장 구조 변경을 완료해 규제
  대응 사실을 함께 홍보하고 싶다. 목표는 4주 이내 완료.
- **개발**: 전체 데이터 이관과 정합성 검증에는 최소 6주가 필요하다고 추정한다.
  4주로 압축하려면 이관 후 정합성 검증 단계를 생략해야 하는데, 이는 데이터
  유실 위험을 키운다.

## Round 1 종료 시점 상태

두 충돌 모두 아직 해결되지 않은 채로 Round 1이 종료됐다. Synthesizer는 두 건 모두
Consensus-Builder에게 넘긴다.
